# 电商运营 AI 资产集

> 电视品类目的 AI 运营资产：指标口径、分析 Skill、提示词库。
> 这些是我 5 年天猫运营经验 AI 化的过程记录。

## 包含什么

| 目录 | 说明 |
|---|---|
| `指标口径/` | GMV、订单量、客单价、转化率等 P0 指标的 8 项定义（含时间归属、常见误用） |
| `skills/` | 可直接导入 AI 工具的 Skill：竞品价格带分析、经营日报生成 |
| `prompts/` | 10 条经过真实数据验证的提示词（抽取/计算/对比/归因/报告） |
| `踩坑记录/` | AI 在电商数据场景的翻车实录，按根因分类统计 |

## 为什么做这个

大模型能写代码、能算数字，但它不知道：
- 电商品类的转化率正常范围是多少
- 竞品到手价要怎么折算才准确
- GMV 用支付口径还是确认收货口径

**这些是行业知识，不是通用知识。** 我在做的，是把它们写成 AI 能读懂的形式。

## 怎么用

### 导入 Skill
把 `skills/` 下的文件夹导入支持 SKILL.md 的 AI 工具（如 Claude Code、WorkBuddy、Cursor）。

### 用指标口径
`指标口径/` 下是机器可读的 YAML，同时含人读版 Markdown。
接入任何 AI 系统前，先让它读这份口径。
